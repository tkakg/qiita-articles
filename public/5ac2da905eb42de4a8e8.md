## はじめに

Amazon RDS を運用していると、一般ログ、エラーログ、スロークエリログ、監査ログを確認したい場面があります。  
本記事では、これらのログを CloudWatch Logs に出力する手順をまとめます。

## 前提

- 対象: RDS for MySQL

## 手順概要

RDS のログを CloudWatch Logs に出力するには、以下が必要です。

1. パラメータグループの設定
2. オプショングループの設定
3. RDSの変更
4. CloudWatch Logs で確認
5. 最終確認

## 1. パラメータグループの設定

デフォルトパラメータを使用している人はカスタムパラメータを使用する必要があります。
デフォルトパラメータは値の変更ができないためです。

今回わたしはmysql8.4を使用していたので8.4で作成しています。

![スクリーンショット 2026-03-11 000952.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/3839634/c0536e5f-f84e-4441-ac69-752115e8b353.png)



注意する必要あるのが、一般ログ、スロークエリログを新たにCloudWatch Logsへエクスポートしたい場合は、デフォルトパラメータグループからカスタムパラメータグループに関連付けを変更する必要があります。
 **一般ログ、スロークエリログは動的なので再起動が必要ないと思われがちですが、RDSに関連づけられているパラメータグループが、デフォルトの場合はカスタムに変更する必要があります。** 
そのため反映のためにはRDSの再起動が必要です。



以下カスタムパラメータグループの設定例です

### 一般ログ

- `general_log = 1`

### スロークエリログ

- `slow_query_log = 1`
- `long_query_time = 2（任意の秒数）`
- `log_output = FILE`

![スクリーンショット 2026-03-11 000103.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/3839634/3415228b-e85b-480e-adbb-db16c6bd6093.png)

https://docs.aws.amazon.com/ja_jp/AmazonRDS/latest/UserGuide/USER_LogAccess.MySQL.LogFileSize.html#USER_LogAccess.MySQL.Generallog



## 2.オプショングループの設定

監査ログを出力するにはデフォルトオプショングループではなく、カスタムオプショングループを使用する必要があります。

下記のように名前は任意でOKです
![スクリーンショット 2026-03-11 001154.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/3839634/b727769b-e791-4d1a-a5d5-af3203f5ba76.png)

オプションの追加（変更）で **MARIADB_AUDIT_PLUGIN** を追加する必要があります。
 **監査ログ** の記録にはこのプラグインが必要です。

特にこだわりがなければ以下の様にデフォのままで問題ないですが、カスタマイズも可能です。
設定が終わったらすぐに適用にYesを付けてオプションの変更を実施してください。
![スクリーンショット 2026-03-11 001300.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/3839634/1158045f-3484-4f70-8351-8c3d67cc303e.png)

https://docs.aws.amazon.com/ja_jp/AmazonRDS/latest/UserGuide/Appendix.MySQL.Options.AuditPlugin.html#Appendix.MySQL.Options.AuditPlugin.Options


:::note alert
MariaDB 監査プラグインを DB インスタンスに追加すると、停止する可能性があります。MariaDB 監査プラグインは、メンテナンス期間中またはデータベースのワークロードが低い時間帯に追加することをお勧めします。
:::


## 3. RDSの変更
RDSの変更ボタンをクリックし、
まずはパラメータグループとオプショングループを先ほど作成したカスタムパラメータグループとカスタムオプショングループに変更してください。
![スクリーンショット 2026-03-11 002330.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/3839634/285da8cd-4173-4717-b486-226fa92d357b.png)

次にログのエクスポートでエラーログ、全般ログ、スロークエリログ、監査ログにチェックを付け、設定を反映してください。
![スクリーンショット 2026-03-11 002358.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/3839634/bc0cd8a2-6686-4d7d-bf21-e35e6afffa45.png)

しかしここで反映しただけではスロークエリログは発行されません。RDSの手動再起動が必要ですので手動で再起動してください。
[DB インスタンスの再起動のユースケース](https://docs.aws.amazon.com/ja_jp/AmazonRDS/latest/UserGuide/USER_RebootInstance.html#:~:text=%E6%96%B0%E3%81%97%E3%81%84%20DB%20%E3%83%91%E3%83%A9%E3%83%A1%E3%83%BC%E3%82%BF%E3%82%B0%E3%83%AB%E3%83%BC%E3%83%97%E3%81%AE%E9%96%A2%E9%80%A3%E4%BB%98%E3%81%91%20%E2%80%93%20%E6%96%B0%E3%81%97%E3%81%84%20DB%20%E3%83%91%E3%83%A9%E3%83%A1%E3%83%BC%E3%82%BF%E3%82%B0%E3%83%AB%E3%83%BC%E3%83%97%E3%82%92%20DB%20%E3%82%A4%E3%83%B3%E3%82%B9%E3%82%BF%E3%83%B3%E3%82%B9%E3%81%AB%E9%96%A2%E9%80%A3%E4%BB%98%E3%81%91%E3%82%8B%E5%A0%B4%E5%90%88%E3%80%81RDS%20%E3%81%AF%E3%80%81DB%20%E3%82%A4%E3%83%B3%E3%82%B9%E3%82%BF%E3%83%B3%E3%82%B9%E3%81%8C%E5%86%8D%E8%B5%B7%E5%8B%95%E3%81%95%E3%82%8C%E3%81%9F%E5%BE%8C%E3%81%AB%E3%81%AE%E3%81%BF%E3%80%81%E5%A4%89%E6%9B%B4%E3%81%95%E3%82%8C%E3%81%9F%E9%9D%99%E7%9A%84%E3%81%8A%E3%82%88%E3%81%B3%E5%8B%95%E7%9A%84%E3%83%91%E3%83%A9%E3%83%A1%E3%83%BC%E3%82%BF%E3%82%92%E9%81%A9%E7%94%A8%E3%81%97%E3%81%BE%E3%81%99%E3%80%82%E3%81%9F%E3%81%A0%E3%81%97%E3%80%81DB%20%E3%82%A4%E3%83%B3%E3%82%B9%E3%82%BF%E3%83%B3%E3%82%B9%E3%81%AB%E9%96%A2%E9%80%A3%E4%BB%98%E3%81%91%E3%81%9F%E5%BE%8C%E3%81%AB%20DB%20%E3%83%91%E3%83%A9%E3%83%A1%E3%83%BC%E3%82%BF%E3%82%B0%E3%83%AB%E3%83%BC%E3%83%97%E3%81%AE%E5%8B%95%E7%9A%84%E3%83%91%E3%83%A9%E3%83%A1%E3%83%BC%E3%82%BF%E3%82%92%E5%A4%89%E6%9B%B4%E3%81%99%E3%82%8B%E3%81%A8%E3%80%81%E3%81%93%E3%82%8C%E3%82%89%E3%81%AE%E5%A4%89%E6%9B%B4%E3%81%AF%E5%86%8D%E8%B5%B7%E5%8B%95%E3%81%9B%E3%81%9A%E3%81%AB%E7%9B%B4%E3%81%A1%E3%81%AB%E9%81%A9%E7%94%A8%E3%81%95%E3%82%8C%E3%81%BE%E3%81%99%E3%80%82%E8%A9%B3%E7%B4%B0%E3%81%AB%E3%81%A4%E3%81%84%E3%81%A6%E3%81%AF%E3%80%81%E3%80%8CAmazon%20RDS%20%E3%81%AE%E3%83%91%E3%83%A9%E3%83%A1%E3%83%BC%E3%82%BF%E3%82%B0%E3%83%AB%E3%83%BC%E3%83%97%E3%80%8D%E3%82%92%E5%8F%82%E7%85%A7%E3%81%97%E3%81%A6%E3%81%8F%E3%81%A0%E3%81%95%E3%81%84%E3%80%82)

## 4. CloudWatch Logs で確認

CloudWatch Logs で以下のロググループが作成されていることを確認します。

- `/aws/rds/instance/<DBインスタンス名>/error`
- `/aws/rds/instance/<DBインスタンス名>/general`
- `/aws/rds/instance/<DBインスタンス名>/slowquery`
- `/aws/rds/instance/<DBインスタンス名>/audit`

※slowqueryに関しては出ていない場合もあります。その際は5.最終確認を参考にしてください。

## 5. 最終確認
slowqueryなどを意図的に発行してみて記録されるかどうか、出力されていない場合は確認すると良いです。
以下コマンドをSQLで実行してください。
スロークエリログが発行されます。

```
SELECT SLEEP(5);
```

最終的に以下4つがCloudWatch Logsに出力されたら完了です。
![スクリーンショット 2026-03-17 9.40.49.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/3839634/6b1a4e17-e84e-4ccb-8a7e-d6247f600604.png)


:::note info
ポイント

- 監査ログの適用で、MariaDB 監査プラグインを DB インスタンスに追加すると、**停止する可能性** がある。
- スロークエリログ、一般ログを出したい時、デフォルトパラメータを使用していた場合は、反映に **RDS再起動が必要**。 （元からカスタムパラメータを使用していた場合は動的に変更できるので再起動不要）
:::
