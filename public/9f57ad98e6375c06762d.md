# 概要
```
% exit

Saving session...
...copying shared history...
...saving history...truncating history files...
...completed.
Deleting expired sessions...none found.

[プロセスが完了しました]
```

う、うわあぁぁぁぁぁぁぁぁぁぁぁぁぁぁぁ！！！！！！！！
Macのターミナルを使っている人なら誰しもが経験あるのではないでしょうか？
私は普段Ctrl+Dをログアウトで使うのですが、誤入力でやってしまうことが多々あります。
そういった時の予防法です。

# 手順

`.zshrcファイル`に`setopt IGNORE_EOF`を追記して`source ~/.zshrc`で保存するだけです。
簡単ですね。


```
vim ~/.zshrc
```
```
#追記
setopt IGNORE_EOF
```

```
source ~/.zshrc
```

### 追記後

追記後は`Ctrl+D`を入力してしまってもさらに追加で`logout`もしくは`exit`と入力しない限り、ログアウトできなくなります。
興味のある人はやってみてね。

```
% 
zsh: use 'logout' to logout.
```
