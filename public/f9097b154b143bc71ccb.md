# パス配下のディレクトリを全て755にする
 ```
 find [パス] -type d -exec chmod 775 {} +
```

### ユーザー、グループがrootのディレクトリのみ変更
```
find [パス] -user root -group root -type d -exec chmod 775 {} +
```

# パス配下のファイルを全て664にする
```
 find [パス] -type f -exec chmod 664 {} +
```
