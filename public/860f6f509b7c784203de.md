今触っているサーバー（AWS）のGIPをサーバー内部からコマンドを使って確認する方法です。

```
curl https://checkip.amazonaws.com
```

これでGIPが確認できます
便利。


※AWSに限らず、アウトバウンド通信できるサーバーの場合以下コマンドでも可能です。
こっちのが汎用性は格段に高いです。

```
 curl https://ipconfig.io
```
