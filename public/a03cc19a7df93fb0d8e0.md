# 概要
エンジニア歴一年未満の私ですが、ターミナルを使う際によく使うショートカットキーを紹介したいと思います。

今回紹介するもの以外にもたくさんあるのは承知ですが、（決して知らないわけではないんだ...!）本当にガチでよく使うものだけ紹介します。
たくさんあっても結局覚えられないし、使う場面も限られてくるので...

カーソル移動

| コマンド | 効果 |
|:-:|:-:|
| Ctrl + a  | 行の先頭に移動  |
|  Ctrl + e | 行の最後に移動  |
| option + ← | 1単語分右に移動|
|option + → |1単語分左に移動|

ぶっちゃけこれだけでも生産性爆上がりします🔥
他にも出てきたら追記しようと思います。
